# 서우놀이터 7.1

첨부된 서우놀이터 레퍼런스의 캐릭터·하늘·파스텔 활동 카드·해저 놀이 공간을 실제 앱으로 옮긴 리빌드입니다. 기존 공개 저장소의 v6.8.1 (`873fa30`)을 기준으로 구성했습니다.

## 실행

Node.js 22 이상에서 다음을 실행한 뒤 `http://127.0.0.1:4173`을 엽니다.

```sh
pnpm install
pnpm dev
```

앱 자체에는 런타임 패키지나 별도 서버가 필요 없습니다. GitHub Pages 같은 정적 호스팅에서 실행됩니다. `index.html`을 파일로 직접 여는 방식은 PWA·보호자 비밀번호 기능을 지원하지 않습니다.

```sh
pnpm test
pnpm build:offline
```

이미지·스타일·코드를 수정하면 `build:offline`을 실행하여 오프라인 캐시 버전을 갱신합니다. 테스트에 필요한 패키지는 개발 의존성입니다.

## 구현 범위

- 홈, 투명 엘리베이터, 화장실 탐험대, 말글 놀이터, 숫자 놀이, 도형 찾기, 영어 찾기, 보호자 메뉴.
- 역할놀이 마을(마트·주방·동물병원), 퍼즐 탐험대(그림자·색깔·그림조각), 마음친구(감정 선택·상황 이해·호흡 진정) 추가.
- 기존 숫자 1–100, 수량·순서·손가락, ABC 카드, 그림 영단어·한글단어, 가나다 리듬, 색깔·기억 놀이, 함께하기, 음악, 보물상자 유지.
- 한글·자음·모음·단어 찾기, 오답 재시도, 짧은 칭찬, 중복 정답 처리 방지, 놀이 기록.
- 엘리베이터 1–8층 우선 표시, 9–20층 펼치기, 문 열림 유지, 이동 중 추가 층 예약, 10개 로컬 도시 배경 선택/랜덤. 층당 1.75초에서 1.2초로 조정했습니다.
- 화장실 8단계, 쉬/응가/괜찮아 선택, 물 내림, 손 씻기 3회, 실제 화장실 다녀오기, 스티커.
- 보호자 PIN 한 번 입력, PIN 변경, 잠금, 음성·효과음·볼륨, 이용시간, 난이도, 숫자 읽기, 캐릭터 인사, 기록 관리. 설치 버튼 없음.
- 기존 `seowoo-play-v3` 기록, `seowoo-screen-lock-pin-v2` 자격정보, Android 네이티브 키오스크 연결 규격 유지.

## 구조

| 파일 | 책임 |
|---|---|
| `css/tokens.css` | 컬러·서체·크기·간격·모션·레이어 |
| `css/app.css` | 공통 화면, 카드, 버튼, 놀이 테마, 반응형 규칙 |
| `js/app.js` | 단일 라우터, 공통 내비게이션, 놀이 화면과 수명 주기 |
| `js/experiences.js` | 역할놀이·퍼즐·마음친구 상호작용과 드래그 상태 |
| `css/experiences.css` | 신규 3개 놀이 전용 장면·캐릭터·반응형 스타일 |
| `js/core.js` | 저장·기록·난이도·숫자 읽기 |
| `js/elevator.js` | 기존 문·층 이동 상태 기계 |
| `js/panorama.js` | 외부 파일 기반 도시 배경과 이동 |

## 검증의 범위

자동 기능 테스트와 Chromium 기반 실제 브라우저의 태블릿/휴대폰 화면 및 터치 흐름을 확인했습니다. `docs/QA.md`에 범위와 증거를 기록했습니다.

iPhone Safari 실기기, 실제 PWA 설치, Android 키오스크 기기 전체 잠금은 이 Windows 환경에서 실기기 검증하지 못했습니다. safe-area, svh/dvh, 좁은 화면, 모달 스크롤을 구현했지만 이 항목의 실기기 확인을 출시 검사로 남깁니다. App Store/Play Store 제출이나 서명된 설치 파일 생성은 이번 웹 리빌드에 포함되지 않습니다.

음성은 앱에 저장된 고정 신경망 음원을 우선 재생합니다. 현재 음성 카탈로그 668개 항목을 661개의 로컬 MP3로 구성했고, 한국어는 `ko-KR-SunHiNeural`, 영어는 `en-US-JennyNeural`을 사용했습니다. 숫자·말글·영어·화장실·기억·가족미션·엘리베이터 등 현재 앱의 모든 유한 음성 경로를 오프라인 설치 캐시에 포함합니다. 로컬 음원 재생이 실패한 경우에만 기기 `speechSynthesis`를 대체 경로로 사용합니다. 효과음도 도착 딩동·문 열림/닫힘·운행·버튼·성공·물내림 8종을 로컬 WAV로 사용합니다.
