## 서우놀이터에 적용한 결정

| 추출 대상 | 적용 |
|---|---|
| 레이아웃 | 상단 단순 내비게이션, 중앙 장면/문제, 아래 큰 활동/답안 |
| 카드 비율 | 태블릿 홈은 세로형 6열, 휴대폰은 3×2. 화면 폭에 따라 비율 조정 |
| 컬러 | 레퍼런스의 sky/mint/yellow/peach/lavender를 기본으로 사용 |
| 타이포 | 큰 둥근 한글 제목과 짧은 안내. 보호자 설명은 고딕 |
| 여백 | 8px 기반 계열, 큰 영역 사이 24/32px |
| 리듬·밀도 | 한 문제 + 3~4개 선택지. 통계·설정은 보호자 화면 |
| 그림 배치 | 캐릭터가 중심을 잡고, 장난감/해저 생물은 가장자리 |
| 터치 | 조작부 최소 48px, 활동/정답은 훨씬 크게 |
| 보호자 분리 | 상단 잠금 진입 → 1회 PIN → 차분한 white/blue 설정 |

공개 UI 사례의 유료 아이템 상점, 경쟁 순위, 채팅 구조는 서우놀이터의 유아 놀이 목적에 맞지 않아 적용하지 않았습니다. 최우선 시각 기준은 사용자가 첨부한 서우·강아지 레퍼런스입니다.
