# 서우놀이터 7.3.0

## 변경 범위

- 역할놀이 마을, 알록달록 마트(8개 장보기 목록), 우리집 주방(3개 요리), 동물 병원(3종 동물·6개 도구)
- 퍼즐 탐험대 12종, 마음친구 12개 이야기·5개 감정·3개 마음 진정 놀이
- 숫자·말글·영어·색깔·기억 놀이, 그림 단어·ABC 카드, 가족 놀이, 음악, 보물상자, 더 놀기와 신규 놀이 선택 카드
- 기존 홈 배경과 여섯 활동 카드, 투명엘리베이터의 동작·수치·속도·파노라마·음원은 유지한다.

## 일러스트와 접근성

앱에 포함한 WebP 그림 167개: 공간 배경 4개, 감정 이야기 12개, 사물·캐릭터·음식·도구 그림 151개. 원본 생성 지시와 추출 범위는 `ART_V3_PROVENANCE.json`에 기록한다. 모바일에서는 게임판을 문서 흐름에 배치해 화면 밖으로 잘리지 않고 세로로 스크롤할 수 있다. 그림 선택 버튼, 음성 다시 듣기, 드래그와 누르기 대체 조작, 동작 줄이기 설정을 지원한다.

퍼즐은 그림을 고른 뒤 알맞은 자리를 눌러야 한다. 그림만 누르는 자동 정답 처리를 없앴다. 크기 비교에서는 작은 그림을 큰 그림의 절반 크기로 유지한다. 손 씻기 순서는 물 묻히기·비누·문지르기·헹구기·수건 순서다. 감정 이야기에서 다른 느낌을 골라도 혼내거나 실패로 기록하지 않는다.

## 음성 구조

기존 `SeowooAudioManager`와 로컬 MP3 재생 경로를 공유한다. 한국어는 기존 Gemini 3.1 Flash TTS Preview / Sulafat 설정을 사용한다. 영어 JennyNeural 음원은 유지한다. 새 음원 매핑을 별도 `play-files.js`로 추가하므로 기존 `audio/files.js`와 기존 MP3를 덮어쓰지 않는다. 배포 후 음성 서비스에 요청하거나 비밀 키를 클라이언트에 넣지 않는다.

`play-dialogue.json`의 148개 대사는 실제 상태에 연결한다. 장보기 목록·찾은 상품·다음 상품, 재료 준비 단계·요리 완성, 진료 도구·완료, 퍼즐 안내·선택·재시도, 감정 이야기·공감, 음악과 메뉴 안내를 포함한다. 녹음 생성 스크립트는 기존 파일을 건너뛴다. 사용하지 않는 준비 대사는 재생하지 않는다.

`SeowooNarrator`는 현재 안내가 끝난 뒤 가장 최근 이벤트만 이어서 읽는다. 그 사이 새 상태가 생기면 지난 안내의 나머지 문장은 버린다. 화면을 나가거나 소리를 끄면 대기 안내를 취소한다. 기존 퀴즈·기억 놀이의 칭찬 음성을 다음 화면 전환으로 끊지 않는다. Safari에서는 실제 사용자 터치로 AudioContext를 해제하며 기존 로컬 HTMLAudio 재시도와 최종 기기 음성 복구 경로를 유지한다.

- 실제 iPhone/iPad 하드웨어와 홈 화면에 설치한 PWA의 OS 오디오 경로는 브라우저 에뮬레이션과 별도 검증 대상이다.

## 캐시

앱과 서비스워커 버전은 7.3.0이다. 코드·스타일은 네트워크에서 갱신하고 실패하면 캐시로 복구한다. 설치 실패 시 새 캐시를 제거해 기존 정상 버전을 유지한다. 그림과 기본 앱·엘리베이터 안내는 설치 시 저장하며 그 밖의 음원은 재생하면서 저장한다. 처음 듣는 안내의 오프라인 재생은 해당 음원이 미리 저장되어 있어야 한다.
