# 서우놀이터 디자인 시스템

레퍼런스의 핵심은 큰 3D 서우·강아지, 맑은 하늘과 정원, 여러 색의 입체 글자, 아래쪽 여섯 파스텔 카드입니다. 태블릿 가로 화면의 이 구도를 기준으로 휴대폰에서는 캐릭터 장면 위·활동 3×2 아래로 재배치했습니다. 모든 화면에 같은 브랜드의 둥근 글꼴과 내비게이션을 사용합니다.

## 공통 컴포넌트

`header()`는 홈/뒤로, 제목, 소리 버튼을 공유합니다. `gameShell()`은 테마 배경과 놀이 콘텐츠 폭을 통일합니다. `question-card`, `answer`, `mode-tabs`, `btn`, `icon-btn`, `learning-card`, `setting-row`가 공통 규칙을 사용합니다.

홈에서는 장면과 활동 카드가 주인공입니다. 말글은 투명한 버블, 숫자는 하늘과 풍선, 도형은 민트 장난감 방, 영어는 라벤더 정원과 토끼로 나눕니다. 화장실은 깨끗한 환경과 단계에 집중합니다. 엘리베이터의 금속·유리 표현은 해당 공간의 물성에 한정합니다.

보호자 화면은 white/blue 다이얼로그로 분리합니다. 비밀번호를 한 번 입력한 후 설정을 변경할 수 있고, 설정 변경에는 아이의 놀이 화면용 장식을 사용하지 않습니다.

## 아이콘·그림

- 서우와 동물, 활동 장난감, 배경은 같은 부드러운 3D 방향으로 생성한 로컬 이미지입니다.
- 기능 아이콘은 한 가지 선 두께의 SVG 집합으로 중앙 관리합니다. 활동 아이콘을 CSS 도형으로 흉내내지 않습니다.
- 기존 단어 데이터의 사물 이모지는 그림 단어 카드 콘텐츠로 유지합니다. 핵심 여섯 활동 및 화장실 카드에는 새 3D 에셋을 사용합니다.
- 텍스트, 버튼, 점수, 진행률은 이미지에 구워 넣지 않고 실제 HTML로 구현합니다.
- 그림은 WebP, 서체는 WOFF2. 배경의 Base64 삽입 및 실행 시 외부 사진 다운로드는 없습니다.

## 반응형

태블릿 가로 6열 홈 카드, 태블릿 세로 및 휴대폰 3×2 홈 카드. 다른 활동은 폭에 따라 4/2열로 바뀝니다. 모바일의 외부 여백은 16px이고 safe area를 더합니다. 놀이 메뉴와 모달은 필요한 방향으로만 스크롤합니다. 작은 화면에서 전체 콘텐츠를 강제로 한 화면에 압축하지 않습니다.
